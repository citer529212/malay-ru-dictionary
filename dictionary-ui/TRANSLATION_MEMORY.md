# Память переводов

Экспериментальный автономный модуль для русско-малайских переводов политических,
культурных, религиозных и военных текстов.

## Статусы

- `machine` — машинный перевод, требует проверки;
- `reviewed` — проверен редактором;
- `verified` — подтверждённый перевод.

Будущий корпус Google следует импортировать со статусом `machine`. Система не
отправляет тексты на сервер: память хранится в `localStorage` браузера.

## Импорт

JSON принимает массив либо объект с полем `segments`. Обязательные поля:
`source` и `target`. Дополнительные: `domain`, `status`, `document`, `author`,
`createdAt`.

CSV использует заголовки:

```csv
source,target,domain,status,document,author
```

Допустимые тематики: `politics`, `culture`, `religion`, `military`.

При повторном импорте точные дубли не добавляются. Более высокий статус проверки
и отсутствующий ранее источник документа могут обновить существующую пару.

## Редакторская работа

- поиск выполняется по русскому оригиналу и малайскому переводу;
- результаты можно фильтровать по тематике и статусу проверки;
- выбор карточки открывает сегмент для редактирования или удаления;
- статистика отдельно показывает машинные, проверенные и подтверждённые пары.

## Экспорт

Доступны JSON и CSV для резервной копии, а также TMX 1.4 для переноса в CAT-системы.
